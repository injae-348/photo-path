# photo-path

사진 속 위치 기록을 시간 순서대로 이어, 이동 경로를 **지도 애니메이션 영상**으로 만들어 줍니다.
설치도 회원가입도 없습니다 — 브라우저에서 열면 끝.

**▶ 바로 쓰기: https://photo-path.vercel.app**

> **개인정보 안내 — 사진은 이 컴퓨터를 벗어나지 않습니다.** 사진도 JSON도 어디로도 업로드되지 않습니다. 받아줄 서버가 없습니다.
> 사진은 앞 64KB만 읽어 위치·시각을 꺼내고, 나머지는 전부 브라우저 안에서 끝납니다.
> 지도 배경도 **기본이 오프라인**이라, 그냥 쓰면 지도 요청조차 나가지 않습니다. → [개인정보와 외부 통신](#개인정보와-외부-통신)

## 동작 흐름

두 개의 페이지가 하나의 파이프라인을 이룹니다.

```
사진 폴더 ─▶ [사진 위치·시간 추출기] ─▶ photos-geo.json ─▶ [사진 이동 경로 지도] ─▶ mp4 · PNG
```

- **[사진 위치·시간 추출기](https://photo-path.vercel.app/photo-geo-extractor.html)** — 폴더 안의 모든 사진에서 위도·경도·촬영일시만 읽어 JSON으로 저장합니다.
- **[사진 이동 경로 지도](https://photo-path.vercel.app)** — 그 JSON을 끌어다 놓으면 이동 경로를 재생하고 영상으로 저장합니다. 추출기를 거치지 않은 구글 위치기록·GeoJSON 등도 그대로 읽습니다.

## 주요 특징

- **사진과 JSON을 업로드하지 않습니다.** 추출과 렌더링은 모두 브라우저 안에서 처리되고, 지도 배경도 기본이 오프라인이라 지도 요청조차 나가지 않습니다.
- **형식을 가리지 않습니다.** 키 이름과 중첩 구조를 스스로 찾아 좌표·시각을 읽고, 위도와 경도가 뒤바뀐 파일도 자동으로 바로잡습니다.
- **릴스·쇼츠용 세로 9:16 영상**을 바로 저장합니다 (mp4, 미지원 브라우저는 webm).
- **10만 장도 처리합니다.** 이미지를 디코딩하지 않고 파일 앞부분 64KB만 읽으므로 메모리 사용이 일정합니다.
- **의존성·빌드가 없습니다.** 순수 HTML/JS 정적 파일 8개가 전부입니다.

## 빠른 시작

1. 좌표가 담긴 JSON이 없다면 — [추출기](https://photo-path.vercel.app/photo-geo-extractor.html)에서 사진 폴더를 선택하고 **추출 시작** → JSON 저장 (Chrome·Edge 권장). 특정 기간만 필요하면 **연도** 칸에 범위를 넣으세요.
2. [지도 페이지](https://photo-path.vercel.app)에 JSON 파일을 끌어다 놓습니다.
3. **▶ 재생**으로 확인하고, 마음에 들면 **● 영상 저장**. 길이는 사진 장수에 맞춰 이미 잡혀 있습니다.

재생 방식(이동 거리에 맞춰 · 사진 순서대로 · 실제 시간 흐름), 카메라(자동 줌 · 따라가기 · 고정), 지도 배경(내장 벡터 · OpenStreetMap), 테마와 경로 색은 화면의 컨트롤에서 바로 바꿀 수 있습니다.
지도 배경은 **내장 벡터(오프라인)** 로 시작합니다. 도로와 지명이 나오는 온라인 지도로 바꾸면 그때부터 지도 서버로 요청이 나가며, 무엇이 전달되는지 배경을 고르는 자리에서 바로 안내합니다.

**연도**를 고르면 그 구간의 사진만 지도·통계·타임라인·영상에 반영됩니다. 여러 해가 섞인 파일에서 "그 여행이 있던 해만" 뽑아 볼 때 쓰세요. 원본은 그대로 들고 있으므로 **전체 기간** 버튼으로 언제든 되돌아옵니다. 추출기 쪽에도 같은 범위 지정이 있어, 애초에 그 기간 사진만 JSON으로 뽑을 수도 있습니다.

**영상 길이**는 사진 장수에 맞춰 자동으로 잡힙니다. 슬라이더로 바꾸면 옆에 **추천 N초** 버튼이 나타나 언제든 되돌릴 수 있습니다.

| 사진 | 400장 | 1,000장 | 2,000장 | 5,000장 | 10,000장 이상 |
|---|---|---|---|---|---|
| 추천 길이 | 12초 | 19초 | 27초 | 42초 | 60초 |

**재생을 누르면** 곧바로 시작 지점으로 건너뛰지 않고, 전체 경로가 보이는 자리에서 시작 지점 쪽으로 이동한 뒤 **천천히 줌인해 들어가면서** 경로를 그리기 시작합니다. 영상 저장에도 이 도입부가 그대로 담깁니다. 카메라를 **고정**으로 두면 이 도입부 없이 지금 보고 있는 화면 그대로 재생합니다.

## 지원 형식

**지도에 넣을 수 있는 파일**

| 형식 | 비고 |
|---|---|
| 추출기 JSON | 아래 스키마 |
| GeoJSON | Feature / geometry 좌표 |
| 구글 위치기록 | Takeout의 `latitudeE7` 형식 |
| 구글 포토 Takeout | 사진별 메타데이터 JSON |
| NDJSON · CSV · TSV | 열 이름 자동 인식 |

**추출기가 읽는 이미지** — JPEG · HEIC/HEIF · AVIF · PNG · WebP · TIFF/DNG, 그리고 TIFF 기반 RAW(CR2·NEF·ARW 등). 대상 확장자 목록은 화면에서 수정할 수 있습니다.

## 추출기 JSON 스키마

```json
[{ "path": "2026/IMG_0001.jpg", "lat": 40.4168, "lon": -3.7038,
   "alt": 655.1, "taken": "2026-04-25T14:03:12", "tz": "+02:00",
   "takenUtc": "2026-04-25T12:03:12Z", "gpsUtc": "2026-04-25T12:03:10Z",
   "model": "iPhone 15 Pro", "size": 3145728 }]
```

값이 없는 필드는 생략됩니다. `taken`은 카메라 로컬 시각, `gpsUtc`는 GPS가 기록한 UTC입니다.
위도·경도가 없는 사진은 결과에서 항상 제외되며, 사유는 화면의 **제외된 사진** 목록에서 확인할 수 있습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 영상 저장이 안 됨 | 온라인 지도 배경을 쓰는 중이라면 기본값인 **내장 벡터 (오프라인)** 으로 되돌리세요. 그러면 항상 됩니다 |
| 영상 중간에 지도가 비어 있음 | 온라인 지도는 화면에 보이는 만큼 그때그때 받아옵니다. **영상 저장 전에 ▶ 재생을 한 번 돌려** 지도를 미리 받아 두세요 |
| 추출기가 "호환 모드"로 뜸 | 폴더 스트리밍 API(File System Access)가 없는 브라우저입니다. Chrome·Edge에서 훨씬 빠릅니다 |
| 무엇을 읽었는지 궁금함 | 파일을 넣은 뒤 인식 결과의 **자세히**에서 어떤 키를 좌표·시간으로 읽었는지 보여줍니다 |
| 로컬에서 열면 느림 | `file://`로 열면 워커를 만들 수 없습니다. 아래처럼 웹서버로 여세요 |

### 로컬 실행

빌드가 없으므로 정적 서버 하나면 됩니다.

```bash
python -m http.server 8642
```

`http://127.0.0.1:8642` 가 지도, `/photo-geo-extractor.html` 이 추출기입니다.

|---|---|

## 개인정보와 외부 통신

**사진과 JSON은 어디로도 올라가지 않습니다.** 받아줄 서버가 없습니다 — 정적 파일 8개가 전부고, 계산은 전부 브라우저가 합니다.
사진은 앞 64KB만 읽어 위치·시각을 꺼내며 원본은 손대지 않습니다. `localStorage`·쿠키 같은 저장소도 쓰지 않아
탭을 닫으면 읽은 내용이 사라지고, 파일은 저장 버튼을 눌렀을 때만 다운로드 폴더에 만들어집니다.

밖으로 나가는 요청은 이것뿐입니다.

| 무엇 | 언제 | 전달되는 것 |
|---|---|---|
| **지도 그림 조각** | 지도 배경을 **OpenStreetMap**으로 바꾼 뒤부터 — 기본값은 오프라인이라 나가지 않음 | 화면에 보이는 지역의 타일 좌표, 접속 IP, 브라우저 종류. 사진·좌표값·촬영 시각·파일 이름은 보내지 않음 |
| **방문·성능 통계** | 지도 페이지를 열 때 — 추출기 페이지에는 없음 | 페이지 URL·유입 경로·국가·브라우저·성능 지표. 쿠키 없음, 24시간 뒤 폐기 |
| **사이트 파일** | 페이지를 열 때 | 접속 기록. 어떤 웹사이트든 동일 |

`fetch` · `XMLHttpRequest` · `WebSocket` · 외부 라이브러리 · 외부 폰트 · 지오코딩 API · 현재 위치 요청은 코드에 없습니다.
타일 요청에는 쿠키가 붙지 않으며(`crossOrigin="anonymous"`), 사내망·자체 호스팅용으로 타일 서버를 직접 지정하면
같은 요청이 그 서버로 갑니다.

### 공유할 때

서비스가 위치를 흘리는 것이 아니라, 만들어진 파일을 건네는 순간 그 안의 위치가 같이 갑니다.
드러나는 정도는 **무엇을 주느냐에 따라 크게 다릅니다.**

| 무엇을 주느냐 | 상대가 알아낼 수 있는 것 |
|---|---|
| `photos-geo.json` | 위경도 소수점 6자리 — 사실상 문 앞. `photos-excluded.tsv`에는 폴더·파일 이름이 그대로 담긴다 |
| **온라인**(OpenStreetMap) 배경으로 만든 영상·PNG | 도로·지명이 함께 찍히므로 **주소 수준까지 특정 가능** |
| **기본(오프라인)** 배경으로 만든 영상·PNG | 배경에 도로도 지명도 축척도 없어 **동네까지는 알기 어렵다.** 남는 건 도시 이름과 경로 모양 |

어느 쪽이든 날짜·도시·방문지 수·이동 거리는 그대로 보입니다. 걱정되면 지도 배경을 기본 그대로 두고,
**연도**로 보여줄 기간만 골라서 만드세요.

## 지도 타일 출처

온라인 배경 지도는 © OpenStreetMap contributors 타일을 사용하며, 저장되는 영상·PNG에
저작자 표시가 자동으로 포함됩니다. 이 표시는 지우지 말고 그대로 쓰세요.
기본 배경인 내장 벡터 지도는 저장소에 포함된 데이터로, 외부 요청 없이 동작합니다.
