사진 이동 경로 지도

추출기가 만든 JSON을 시간 순서대로 지도에 그립니다.

JSON 파일을 여기에 끌어다 놓으세요
GeoJSON · 구글 위치기록 · 구글 포토 takeout · NDJSON · CSV도 그대로 읽습니다
Ctrl + 휠로 지도를 확대·축소합니다
타일 서버 직접 지정 (사내망·자체 호스팅용)

이동 거리에 맞춰는 사진 한 장에 같은 시간을 주는 대신, 멀리 이동한 구간에 화면 시간을 더 줍니다. 골목 150m와 대륙 횡단 10,000km가 같은 속도로 지나가 순간이동처럼 보이는 걸 막습니다. 이동 강조를 올릴수록 이동 구간이 길어지고, 0으로 내리면 사진 순서 균등과 같아집니다.
자동 줌은 지금 지점 주변만 화면에 담습니다. 도시 안을 걸을 땐 골목까지 들어가고, 비행 직전에 미리 넓어졌다가 착륙하면 다시 들어갑니다. 지도를 드래그하거나 Ctrl+휠로 확대하면 자동 줌이 꺼집니다 — 휠만 굴리면 페이지가 스크롤됩니다.
비행 구간은 점선입니다 — 300km를 넘거나 시속 200km를 넘는 이동을 골라냅니다.
지도 배경은 모두 저작자 표시만 지키면 쇼츠·릴스에 올려도 되는 소스만 담았습니다. 경로 색을 고르면 선·방문지 점·현재 위치가 한 번에 바뀝니다 (↺로 테마 기본색 복귀). 부드러운 선을 켜면 꺾인 경로를 곡선으로 다듬어 그립니다. 사진 지점은 전부 지나갑니다.
파일 형식은 가리지 않습니다. 키 이름과 중첩 구조를 스스로 찾아서 위경도·시각을 뽑아내고, 무엇을 어떤 키에서 읽었는지 위에 표시합니다. 잘못 읽었으면 거기서 바로 보입니다. 위경도가 뒤바뀐 파일은 자동으로 되돌리고, 시간대 표기가 없는 로컬 시각은 오프셋 필드가 있으면 환산합니다.
영상 저장은 브라우저가 지원하면 mp4(H.264)로 나와서 릴스·쇼츠에 바로 올릴 수 있고, 지원하지 않는 브라우저에서만 webm으로 나옵니다. 저장 후 안내 문구에서 어느 쪽인지 알려줍니다. 타일 지도를 쓸 때 저장이 막히면 배경을 내장 벡터로 바꾸면 항상 됩니다.
